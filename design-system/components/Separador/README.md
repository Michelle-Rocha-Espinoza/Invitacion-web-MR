# Separador

Filete dorado (`oro`) con una estrella de cuatro puntas al centro; separa título y texto, o una sección de la siguiente.

**El consumidor entrega:** el SVG de la estrella como único hijo (`<svg viewBox="0 0 16 16"><path d="M8 0c1.2 3 1.8 4.8 8 8-6.2 3.2-6.8 5-8 8-1.2-3-1.8-4.8-8-8 6.2-3.2 6.8-5 8-8z"/></svg>`). Ancho máximo 240px, centrado.

- `.mb-separador`: filete simple, bajo títulos.
- `.mb-separador--doble`: filete doble, para cerrar una sección o enmarcar la fecha.

**Sí:** uno por bloque, entre el título en lettering y el cuerpo. **No:** apilar dos seguidos, cambiar el dorado por otro color, usar emojis o corazones como ornamento.
