# RelieveFloral

Tarjeta con borde floral estampado en seco, como el papel de algodón grabado de las invitaciones físicas: rosas en las esquinas, ramas onduladas con hojas en los cantos, todo del mismo color del papel y visible solo por luz y sombra.

**El consumidor entrega:** un `.mb-relieve-floral` con un `<svg class="mb-relieve" data-mb="relieve">` y un `.mb-relieve-floral__contenido` con el texto. `MarmolBlonda.iniciar()` mide la tarjeta y dibuja el relieve; se redibuja al cambiar de tamaño.

- Papel `papel-relieve`, texto `en-encaje` (oscuro también en el tema Vino).
- `.mb-relieve--oscuro` sobre el SVG: el mismo relieve sobre `banda` (lo usa el bolsillo del `Sobre`).
- El relieve ocupa unos 60px por lado: el contenido lleva 70px de relleno vertical y 56px lateral.

**Sí:** usarla para el bloque más ceremonioso: padres, bienvenida, versículo. **No:** más de una por pantalla, ni sobre fondos blancos puros (el relieve no se ve).
