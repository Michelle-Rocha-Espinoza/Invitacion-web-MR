# Confirmacion

Formulario de confirmación de asistencia (RSVP) dentro de una tarjeta troquelada: campos con subrayado dorado, opciones en píldora y un botón principal.

**El consumidor entrega:** el plazo de respuesta, los campos (nombre siempre; asistencia y número de personas como `.mb-opcion` radio; restricción alimentaria opcional) y el envío de los datos (formulario propio, Google Forms o una base de datos: este sistema no envía nada).

- Etiquetas en máquina mayúscula y `tinta-suave`; inputs con borde inferior `oro` y anillo `foco`.
- Tras enviar, reemplaza el formulario por "¡Gracias, {nombre}! Te esperamos." en `firma`.

**Sí:** máximo cinco preguntas, cada control con `id` y `label`. **No:** pedir datos que no se usarán, ni campos obligatorios sin marcar.
