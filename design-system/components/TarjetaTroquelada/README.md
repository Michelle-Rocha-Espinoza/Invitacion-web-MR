# TarjetaTroquelada

Tarjeta de papel con borde festoneado (troquel) y doble marco interior dorado, uno sólido y uno picado; agrupa un dato concreto: ceremonia, recepción, regalos o contacto.

**El consumidor entrega:** el contenido (eyebrow, título en lettering, dato, dirección) y el envoltorio `.mb-sombra-papel` si quiere sombra (la máscara del troquel corta el `box-shadow`).

- `.mb-troquel`: papel `superficie`, festón `troquel-feston` (12px).
- `.mb-troquel--fino`: festón `troquel-fino` (7px) para tarjetas chicas.
- `.mb-troquel--banda`: papel `banda` con texto `en-banda`.

**Sí:** máximo dos tarjetas lado a lado en escritorio y una por fila en móvil, sobre mármol o `fondo-alterno`. **No:** esquinas redondeadas, ni marcos de un color distinto a `oro`.
