# PanelMarmol

Sección sobre mármol veteado en rubor, con doble filete dorado inset, monograma en lámina dorada y ventana en arco para la foto; es la pieza escultórica de la invitación: portada o mensaje de bienvenida.

**El consumidor entrega:** el monograma (iniciales), una foto dentro de `.mb-arco` (`<img>` con `object-fit: cover` y ancho 100%), un párrafo de máximo tres líneas y la firma.

- Textura: `.mb-marmol` (SVG generado, sin imágenes externas).
- Monograma: `.mb-iniciales.mb-iniciales--foil` (M y R entrelazadas) dentro de `.mb-panel-marmol__monograma`. Para un monograma grabado sin color usa `.mb-relieve-texto`.
- Foto: `.mb-arco` (ventana de capilla) u `.mb-ovalo` (camafeo), ambos con filete `oro`.

**Sí:** uno por página; fotos cálidas o en blanco y negro. **No:** texto largo sobre las vetas, ni fotos con fondos saturados.
