# Boton

Botón en forma de píldora, con texto de máquina en mayúsculas espaciadas y relieve estampado (`sombra-relieve`).

**El consumidor entrega:** un `<button>` o `<a>` con la clase y un texto de verbo + objeto ("Confirmar asistencia", "Ver mapa"). Alto mínimo 48px.

| Variante | Uso |
| --- | --- |
| `.mb-boton` | La acción principal de la pantalla: confirmar asistencia. Una por sección. |
| `.mb-boton--contorno` | Acciones secundarias sobre `fondo` o `superficie`: ver mapa, ver lista de regalos. |
| `.mb-boton--oro` | Acción ceremonial con doble filete dorado: agendar fecha, abrir galería. |
| `.mb-boton--en-banda` | Cualquier botón sobre `banda` (vino). Doble filete `oro`, texto `en-banda`. |

**Sí:** foco visible de 2px en `foco`. **No:** esquinas rectas, íconos de librerías genéricas, más de dos botones lado a lado.
