# PorCompletar

Marcas para borradores y demos: una etiqueta con borde dorado punteado para avisos ("Fecha por confirmar") y un subrayado punteado para un dato que falta dentro de una frase.

**El consumidor entrega:** el texto del aviso en `.mb-pendiente`, o el nombre del dato en `.mb-campo-pendiente` ("Nombre y apellido", "Por completar").

**Sí:** marcar todo dato inventado o faltante mientras la invitación es un borrador. **No:** dejar ninguna de estas marcas en la versión que se envía a los invitados.
